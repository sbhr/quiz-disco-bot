# Discord 早押しクイズBot

Discordのボイスチャンネル上で動作する、読み上げ機能付きの早押しクイズBotです。

## 特徴
*   **自動読み上げ**: gTTSを使用して問題文をボイスチャンネルで自動的に読み上げます。
*   **早押しシステム**: Discordのボタン機能（UI View）を利用し、一番早くボタンを押したユーザーに解答権を与え、音声を即座に停止します。
*   **AI回答判定 (Gemini API)**: Gemini API（AI）を使用することで、ひらがな判定、カタカナ/英字、名字のみの回答、多少の表記揺れを柔軟に「正解」として扱えるようになりました。
*   **ジャンル選択パネル**: クイズ開始時にボタンでジャンルを選べる直感的なUIを搭載しています。

## 必要な環境
*   Python 3.8以上
*   **FFmpeg** (音声再生に必須)

## セットアップ

1. **リポジトリのクローン**
   ```bash
   git clone <repository-url>
   cd quiz-disco-bot
   ```

2. **仮想環境の構築とパッケージのインストール**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windowsの場合は venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **環境変数の設定**
   `.env.template` をコピーして `.env` ファイルを作成し、ご自身のBotトークンを設定してください。
   ```bash
   cp .env.template .env
   ```
   ```env
   # .env の内容
   DISCORD_BOT_TOKEN=あなたのBotトークン
   GEMINI_API_KEY=あなたのGemini_APIキー  # AI判定に使用
   ```

4. **Discord Botの権限設定（Developer Portal）**
   *   `bot` および `applications.commands` スコープでサーバーに招待してください。
   *   Privileged Gateway Intents の **Message Content Intent** を必ず有効にしてください。

## 起動方法
```bash
python main.py
```

## 遊び方

このBotは、複数問を通して勝敗を決める「クイズセッション」形式に対応しています。

### クイズの開始方法
1. ボイスチャンネルに参加します。
2. テキストチャンネルで `/quiz` コマンドを実行してクイズを開始します。
   この際、以下のオプションで対戦ルールを決めることができます。
    * **rule**: `N問先取`（誰かが目標ポイントに達するまで）または `全N問`（指定された問題数で終了）
    * **value**: 問題数または目標ポイント（デフォルトは3）
    * **genre**: 出題するジャンル（指定しない場合はボタンで選択、`all`ですべて）

### 参加者の管理
クイズはデフォルトで「コマンド実行時にボイスチャンネルにいる全員」が参加者となります。
特定の人のみで対戦したい場合は、**クイズ開始前**に以下のコマンドで参加者を募集してください。
* `/recruit` : 参加者を募集するためのパネルをテキストチャンネルに表示します。パネル上の「参加する」ボタンを押した人のみがクイズの解答権を得ます。パネルにはリアルタイムで現在の参加予定者が表示されます。

### クイズの進行ルール
1. 問題が読み上げられます（冒頭に「問題。」と入ります）。分かったら画面に表示される「🔴 早押し！」ボタンを押してください。
2. ボタンを最も早く押したユーザーが解答権を得ます。（読み上げは即座に停止します）
3. 10秒以内にテキストチャットで解答を送信してください。
4. **回答権は1問につき1人1回まで**です。間違えたり時間切れになったりした場合、その問題では再度ボタンを押すことはできません。
5. もし誰も分からない場合は「🏳️ 降参する」ボタンを押してください。
6. 正解が出るか、参加者全員が「不正解」または「降参」の状態になるとその問題は終了し、指定された終了条件を満たすまで自動的に次の問題へと進みます。

### タイムアウトとカウントダウン
- 問題の読み上げが完了するまではタイムアウトしません。
- 読み上げが完了した時点から **7秒間のカウントダウン** が始まります。
- 7秒以内に誰もボタンを押さなかった場合、自動的に次の問題へ進みます。

### セッションの終了
* 指定した終了条件を満たすと、ランキングが発表されてセッションが終了します。
* 途中で強制終了したい場合は `/stop_quiz` コマンドを実行してください。

## クイズの追加・編集とジャンル（CSV）指定
クイズの問題は `data/` フォルダ内のCSVファイルで管理されています。

### CSVファイルの追加
新しいジャンルのクイズを追加したい場合は、`data/` フォルダの中に新しくCSVファイル（例: `anime.csv`）を作成してください。
`data/` フォルダに置かれたすべての `.csv` ファイルは、Bot起動時に自動的に読み込まれます。

*列構成: `question` (問題文), `answer` (正解), `explanation` (解説)*
※ `explanation` 列は省略可能です。

### ジャンルの選択
`/quiz` コマンドを実行する際、オプションの **`genre`** を空欄にすると、現在利用可能なジャンルがボタンとして表示されます。
ボタンを押すだけで簡単に出題範囲を選択できます。

直接指定したい場合は、CSVファイルの名前（`.csv`を除いた部分、例: `anime`）を入力することで、そのファイルの問題だけから出題させることができます。
`all` を指定した場合は、`data/` フォルダ内にある**すべてのCSVファイルの問題が混ざって出題**されます。

> **Note**: `questions.csv` 以外の追加したCSVファイルは `.gitignore` によってGitの管理対象外に設定されているため、コミットに混ざる心配はありません。ご自由に問題を追加してお楽しみください。

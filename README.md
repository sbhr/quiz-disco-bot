# Discord 早押しクイズBot

Discordのボイスチャンネル上で動作する、高性能な読み上げ機能とAI判定を備えた早押しクイズBotです。

## 特徴
*   **爆速・高音質読み上げ**: `edge-tts` を使用し、自然なニューラル音声で問題を読み上げます。（エラー時は自動的に `gTTS` に切り替わります）
*   **プレミアムな視覚演出**: すべてのメッセージを `discord.Embed` でリッチに表示。順位表や正解発表も見やすくなっています。
*   **ミリ秒（ms）単位の早押し反応速度表示**: 問題文の読み上げ開始からボタンが押されるまでの経過時間を1ms単位で精密に計測。解答フォームやチャット上でコンマ数秒の熱い競争を視覚化します。
*   **⚡「神押し賞（最速正解記録）」表彰**: クイズ終了時の最終ランキング発表前に、そのセッションで「最も速い反応速度で正解したプレイヤー」を豪華な専用 Embed カードで表彰します。
*   **AI回答判定 (Gemini API)**: AIを使用することで、表記揺れ、名字のみ、類義語などを柔軟に判定。API制限時には自動で曖昧判定に切り替わるタフな設計です。
*   **事実誤認ゼロへ！高精度クイズ自動生成スクリプト**: Geminiの自己検証（Generator-Verifier デュアルエージェント）を採用し、ファクト誤認（ハルシネーション）や答えの曖昧さを徹底的に排除したクイズCSV自動作成機能を同梱。APIレート制限（429エラー）を自動回避する待機リトライ機構も内蔵しています。
*   **生涯成績の記録 (SQLite)**: Botを再起動しても過去の「累計正解数」と「優勝回数」が保存されます。
*   **出題重複の完全回避 (SQLite)**: 1回出た問題は自動的に記憶され、再起動しても二度と出題されません。ジャンルごとの問題（または全データセット 'all' の問題）がすべて出尽くすと、自動的に履歴がリセットされます。
*   **高度なルール設定**: 「目標ポイント先取」や「全N問」に加え、不正解時に一定時間解答を禁止する「お手つきペナルティ」も設定可能です。

## 必要な環境
*   Python 3.8以上
*   **FFmpeg** (音声再生に必須)

## セットアップ

1. **リポジトリのクローン**
   ```bash
   git clone <repository-url>
   cd quiz-disco-bot
   ```

2. **パッケージのインストール**
   ```bash
   pip install -r requirements.txt
   ```

3. **環境変数の設定**
   `.env` ファイルを作成し、BotトークンとGemini APIキーを設定してください。
   ```env
   DISCORD_BOT_TOKEN=あなたのBotトークン
   GEMINI_API_KEY=あなたのGemini_APIキー
   ```

## コマンド一覧

### クイズを開始・管理
*   `/quiz`: クイズを開始します。
    *   `rule` (ルール): 「目標ポイント先取」または「全N問」
    *   `value` (設定値): 目標ポイントまたは問題数
    *   `genre` (ジャンル): 出題ジャンル（未指定ならジャンル選択ボタンを表示）
    *   `penalty_type` (ペナルティの種類): `none` (なし) / `time` (時間休み) / `skip` (問題数休み) / `disqualify` (お手つき回数で失格)
    *   `penalty_value` (ペナルティの値): 秒数、休み問数、または失格となる最大お手つき回数の数値
    *   `unique` (重複回避): 1回出た問題を出さないようにする（重複回避）か（True/False、デフォルトTrue）
*   `/recruit`: 参加者を募集するパネルを表示します。
*   `/stop_quiz`: 進行中のクイズを強制終了します。
*   `/unmute_all`: **【緊急救助用】** 万が一システムエラー等でマイクミュートが解除されなかった場合に、参加者全員のミュートを強制解除します。

### 成績を確認
*   `/stats`: 自分、または指定したユーザーの通算成績（累計正解・優勝回数）を表示します。

## 遊び方
1. ボイスチャンネルに参加し、`/quiz` を実行します。
2. ジャンルを選択すると読み上げが始まります。
3. **「🔴 早押し！」** ボタンを押して解答権を得ます。
4. 10秒以内にテキストチャットで解答を送信してください。
5. 正解するとポイントを獲得！誰かが目標に達するか指定問数に達すると、最終ランキングおよび **「⚡ 神押し賞（最速正解者）」** が発表されます。

## 開発・カスタマイズ

### 1. 手動で問題を追加する
`data/` フォルダにCSVファイル（`question,answer,explanation`）を追加するだけで、自動的にBotのジャンルとして追加・認識されます。
データは `data/quiz.db` に保存されます。

### 2. AIで高精度な問題を自動生成する
同梱されている高精度クイズ自動生成スクリプトを使って、特定のテーマからハルシネーション（事実誤認）の無い高品質なクイズを自動生成し、即座にBotのジャンルに反映できます。

```bash
# 仮想環境の有効化後、スクリプトを実行します
python scratch/generate_quiz.py --theme "宇宙開発" --num 5
```
*   `--theme`: 生成したいクイズのテーマ（例: 「日本の歴史」「ITトレンド」「宇宙開発」など）
*   `--num`: 生成する問題数（デフォルト: 10問）

このスクリプトは、クイズの生成後にファクトチェック監査エージェントが動作し、事実関係の誤りや早押しとしての読みやすさを検証します。不合格となった場合はその場で正しい内容に自動修正された後、`data/テーマ名.csv` として自動保存されます。

---
> [!NOTE]
> AI判定およびクイズ自動生成を利用するには有効な Gemini API キーが必要です。キーがない場合、または制限に達した場合は、自動的に文字ベースの曖昧判定が使用されます。

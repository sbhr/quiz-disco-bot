# Discord 早押しクイズBot

Discordのボイスチャンネル上で動作する、高性能な読み上げ機能とAI判定を備えた早押しクイズBotです。

## 特徴
*   **爆速・高音質読み上げ**: `edge-tts` を使用し、自然なニューラル音声で問題を読み上げます。（エラー時は自動的に `gTTS` に切り替わります）
*   **プレミアムな視覚演出**: すべてのメッセージを `discord.Embed` でリッチに表示。順位表や正解発表も見やすくなっています。
*   **AI回答判定 (Gemini API)**: AIを使用することで、表記揺れ、名字のみ、類義語などを柔軟に判定。API制限時には自動で曖昧判定に切り替わるタフな設計です。
*   **音声回答機能 & 自動マイク制御 (Speech-to-Text)**: テキストチャット入力に加え、ボイスチャンネル上での音声回答に対応（オン/オフ切り替え可能）。解答権を獲得したメンバー以外のマイクを自動でサーバーミュートし、判定後に自動解除する高度なマイク制御を備えています。発話された音声はGemini APIにより高精度に自動文字起こし＆セマンティック判定されます。
*   **生涯成績の記録 (SQLite)**: Botを再起動しても過去の「累計正解数」と「優勝回数」が保存されます。
*   **出題重複の完全回避 (SQLite)**: 1回出た問題は自動的に記憶され、再起動しても二度と出題されません。ジャンルごとの問題（または全データセット 'all' の問題）がすべて出尽くすと、自動的に履歴がリセットされます。過去の回答判定ログからの自動引き継ぎ（インポート）にも対応しています。
*   **高度なルール設定**: 「目標ポイント先取」や「全N問」に加え、不正解時に一定時間解答を禁止する「お手つきペナルティ」も設定可能です。

## 必要な環境
*   Python 3.8以上
*   **FFmpeg** (音声再生・録音に必須)

## セットアップ

1. **リポジトリのクローン**
   ```bash
   git clone <repository-url>
   cd quiz-disco-bot
   ```

2. **パッケージのインストール**
   ```bash
   pip install -r requirements.txt
   ```

3. **環境変数の設定**
   `.env` ファイルを作成し、BotトークンとGemini APIキーを設定してください。
   ```env
   DISCORD_BOT_TOKEN=あなたのBotトークン
   GEMINI_API_KEY=あなたのGemini_APIキー
   ```

## コマンド一覧

### クイズを開始・管理
*   `/quiz`: クイズを開始します。
    *   `rule`: 「目標ポイント先取」または「全N問」
    *   `value`: 目標ポイントまたは問題数
    *   `genre`: 出題ジャンル（未指定ならボタン選択）
    *   `penalty`: 不正解時の休み時間（秒、デフォルト0）
    *   `unique`: 1回出た問題を出さないようにする（重複回避）か（True/False、デフォルトTrue）
    *   `voice_answer`: 音声で回答するかどうか（True/False、デフォルトFalse）
*   `/recruit`: 参加者を募集するパネルを表示します。
*   `/stop_quiz`: 進行中のクイズを強制終了します。

### 成績を確認
*   `/stats`: 自分、または指定したユーザーの通算成績（累計正解・優勝回数）を表示します。

## 遊び方
1. ボイスチャンネルに参加し、`/quiz` を実行します（音声で回答したい場合は、`voice_answer` を `True` に設定します）。
2. ジャンルを選択すると読み上げが始まります。
3. **「🔴 早押し！」** ボタンを押して解答権を得ます。
4. 解答方式に応じて答えを送信します。
   - **通常（テキスト）**: 10秒以内にテキストチャットで解答を送信してください。
   - **音声回答モード**: 解答権を得た瞬間に解答者以外のマイクが自動でサーバーミュートされ、5秒間の録音が開始されます。録音が終了するとマイクのミュートが自動解除され、発話内容が自動で判定されます。
5. 正解するとポイントを獲得！誰かが目標に達するか指定問数に達すると、最終ランキングが発表されます。

## 開発・カスタマイズ
- **問題の追加**: `data/` フォルダにCSVファイル（`question,answer,explanation`）を追加するだけで自動認識されます。
- **データ保存**: `data/quiz.db` にすべての成績が保存されます。（自動生成され、Gitの管理外となります）

---
> [!NOTE]
> AI判定および音声文字起こし判定を有効にするには有効な Gemini API キーが必要です。キーがない場合、または制限に達した場合は、自動的に文字ベースの曖昧判定が使用されます。
